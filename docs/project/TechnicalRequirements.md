# Technical Requirements

Date: 24 Sep 2026

## Preamble

The purpose of this document is to draft and annotate the exact technical requirements for Project Pipeline alongside segmentation for each component of the application.

### Client Needs - S1/2

- Web/Windows App

- Connected API with 3rd Party LLM

- Read/Import function to process images, text and pdfs.

- Result export function to send results with text analysis and actionable results

- Functional for technical users

- Must be well documented and cheap for use by further students

- Personality Simulation

### Extra Student Deliverables S3/4/5

- Prompt/Guideline Optimisation

- Local host for LLM

- Video Game Analysis

- User friendly UI/UX

- Chat function for further quieries

- Project/Version directories & comparisons

- Visual feedback/results

- Complex game analysis

- Cloud Backups

- Rating System

- AI Model Toggle

- Game Comparison

- Feedback Dashboard

### Alpha Release - S1

- CLI UI with Dashboard, Import & Export pages

- Connected API with 3rd Party LLM

- Read/Import Function to process images and text

- Result Export Function to send results with text

- Basic analysis

### Beta Release - S2/3 (Client MVP)

- Web/Windows App

- Basic UI for users capable of technical understanding

- Connected API with 3rd Party or local LLM

- Read/Import function for multiple files, both text prompts, general files and images

- Result Export Function to send results with text with analysis and actionable results

### Full Release - S4/5

- Web/Windows App

- Animated/Fully Designed UI for non technical users

- Connected API with 3rd Party or local LLM

- Read/Import function for multiple files, both text prompts, general files and images

- Chat function for further queries

- Result Export Function to send results with text and diagrams with analysis and actionable results

- Tested optimisation with different types of engineered prompts and guidelines

- Visualised simulations?

- Basic functionality on digital video game analysis
