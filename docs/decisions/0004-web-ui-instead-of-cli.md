# 0004. Web UI instead of a CLI UI

**Status:** accepted (2026-10-01)

## Context

The Technical Requirements (24 September 2026) planned a CLI UI with a dashboard for the Alpha release.

## Decision

In the group meeting of 1 October 2026 the team decided to drop the CLI UI and to go straight to a web UI. A CLI UI is too clumsy for deployment and testing. Ralph made the first wireframe.

## Consequences

- The Alpha release scope in the Technical Requirements is out of date for the UI.
