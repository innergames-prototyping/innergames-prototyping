# Specs

One folder per story: `context/specs/<story>/spec.md`. Copy `template.md` to start. Read only the spec of the task you work on.

The spec has three parts:

- **Spec**: behaviour and success criteria, no technology.
- **Plan**: stack, architecture, constraints and the ADRs that apply.
- **Tasks**: small ordered build steps, each with its own test or check.

Size the spec to the change. A small fix gets a short spec.
