# 0004. Web UI instead of a CLI UI

Status: accepted (2026-10-01)
Human version: `docs/decisions/0004-web-ui-instead-of-cli.md`

## Decision

The user interface is a web UI. There is no CLI UI.

## Rules

- Do not build a command-line interface for users.

## Consequences

- The Alpha release in the Technical Requirements still names a CLI UI. This ADR replaces that part.
